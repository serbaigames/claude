# Искра — Unity-версия

> **Flutter-версия** — в папке [`iskra_flutter/`](iskra_flutter/README.md): та же игра на Dart для Android, iOS и веба,
> с сохранениями в формате браузерной версии и прежним PHP-сервером учётных записей и рейтингов (`iskra_flutter/server/`).

Перенос браузерной игры «Искра» (мир шестигранников, тьма, искра и прыжки) на Unity 6.
Логика игры перенесена из веб-версии без изменения баланса, интерфейс собран на **UI Toolkit**
(UXML + USS + Painter2D) по скиллам официального Unity-плагина для Claude Code.

## Как запустить

1. Установите **Unity 6** через Unity Hub (проект настроен на 6000.3 LTS; подойдёт любая 6000.x).
2. Unity Hub → **Add → Add project from disk** → выберите корень этого репозитория.
   Если Hub предложит другую версию редактора — соглашайтесь.
3. При первом открытии редактор сам создаст сцену `Assets/Iskra/Scenes/Main.unity`
   и добавит её в сборку. Если этого не случилось — меню **Искра → Настроить проект**.
4. Нажмите **Play**. Игра запускается из любой сцены: `IskraBootstrap` сам создаёт камеру,
   панель UI Toolkit и игру.

Другой вариант: создайте новый проект из шаблона **Universal 2D** и скопируйте в него папку `Assets/Iskra`.

После первого открытия Unity создаст `.meta`-файлы — закоммитьте их вместе с ассетами.

| Действие | Мышь / касание | Клавиатура |
|---|---|---|
| Выбрать клетку | клик по клетке | — |
| Двигать карту | перетаскивание | — |

## Что перенесено

- **Мир**: шестигранная сетка, туман войны, рост клеток тьмы, агрессивность мира, клетки под угрозой и защита.
- **Экономика**: материя, шахты, заводы, башни, укрепления, комплексы, уровни клеток, ячейки строений.
- **Бой**: автоатака, 18 способностей с откатами, 6 особенностей сущностей, 4 ранга (вплоть до легендарной),
  выпадение способностей с выбором ячейки, штрафы при поражении и отступлении.
- **Прогноз боя**: 120 прогонов боя с вашими параметрами, как в веб-версии.
- **Персонаж**: 6 параметров со штрафом за перекос, очки параметров (ОП) и способностей (ОС), покупка ×1/×10/×100/MAX.
- **Эры**: 24 эры со своими эффектами, смена каждые 1–10 минут.
- **Артефакты**: 11 видов, включая ядра искры; **пульсары и технологии**; **прыжок искры** с бонусами.
- **Сохранение**: автоматически каждые 5 секунд и при сворачивании, JSON в `Application.persistentDataPath`.

Пока не перенесено: учётные записи и рейтинги (PHP-сервер в веб-версии). Для них в Unity подходит
Unity Gaming Services (скилл `build-live-game` плагина Unity) или запросы к тому же PHP API через `UnityWebRequest`.

## Устройство проекта

```
Assets/Iskra/
  Scripts/Core/       — вся логика игры, чистый C# без UnityEngine (asmdef с noEngineReferences)
    Defs.cs             справочники: ранги, способности, эры, особенности, артефакты, баланс
    Model.cs            сохраняемое состояние (совместимо с JsonUtility)
    Game.cs             мир, экономика, персонаж, рост тьмы
    GameBattle.cs       бой
    GameMeta.cs         прокачка, артефакты, прыжок
    GameForecast.cs     прогноз боя и оценка состояния мира
  Scripts/Runtime/    — Unity-слой
    IskraApp.cs         точка входа, сохранение, автозапуск
    UI/                 карта (Painter2D), арена боя, иконки, меню, окна
  Scripts/Editor/     — меню «Искра»: сцена, сборка, сброс сохранения
  Resources/Iskra/    — Main.uxml, Iskra.uss, тема IskraTheme.tss
  Fonts/              — PT Sans и Philosopher (SIL OFL 1.1), сконвертированы из woff2
Tools/
  IskraSim/           — консольная симуляция ядра: бот играет без Unity (dotnet run)
  UnityCheck/         — проверка компиляции Unity-скриптов на заглушках API (dotnet build)
.claude/settings.json — подключает официальный плагин Unity для Claude Code
```

Ядро отделено от Unity, поэтому его можно проверять без редактора:

```bash
dotnet run --project Tools/IskraSim -- 1 90        # сид 1, 90 минут игры
dotnet run --project Tools/IskraSim -- 4 120 rich  # с подкачкой материи: проходит все механики
dotnet build Tools/UnityCheck                      # компиляция Runtime/Editor-скриптов на заглушках
```

## Скиллы Unity для Claude Code

`.claude/settings.json` подключает маркетплейс `Unity-Technologies/unity-agent-plugin` и включает
плагин `unity`. При следующем запуске Claude Code в этом репозитории появятся скиллы `/unity:…`:
`new-unity-project`, `unity-cli`, `ui`, `ui-uitk`, `unity-package-management`, `optimize-web`,
`localization`, `build-live-game` и другие. Вручную: `/plugin marketplace add Unity-Technologies/unity-agent-plugin`,
затем `/plugin install unity@unity-agent-plugin`.
