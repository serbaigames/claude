# Сайт ASB studio

Статический сайт студии: HTML, CSS и JS без сборки.

- `index.html` — идея студии, карта миров и реализованные проекты (пока «Искра», iskraplay.ru).
- `support.html` — страница с предложением поддержать разработчика.
- `script.js` — в начале файла объект `SUPPORT`: впишите туда свои ссылки на донаты, подписку и номер карты.

Посмотреть локально: откройте `index.html` в браузере или запустите `python3 -m http.server` в этой папке.
Для публикации подойдёт любой статический хостинг (GitHub Pages, Netlify, свой сервер): загрузите содержимое папки `site/`.
