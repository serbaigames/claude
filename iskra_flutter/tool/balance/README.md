# Тесты баланса (временные)

Ветка только для тестов: исходник игры (`lib/`) не меняется, здесь лежит лишь бот и скрипты прогонов.
Ядро подключается относительным импортом, поэтому хватает голого Dart SDK (Flutter не нужен).

- `bot.dart` — бот, играющий по стратегии: захват, шахты/заводы/башни, укрепление клеток под угрозой,
  покупка ОП/ОС, прокачка параметров и способностей, выбор связок, артефакты, технологии, прыжок,
  когда рост встал или тьма отняла 40% клеток.
- `run.dart` — прогон стратегий: `dart run tool/balance/run.dart [часы] [сиды] [стратегии] [out.json]`.
  Стратегии: balanced, fighter, economist, tank, skew, turtle, turtleJump, noJump, turtleLate, fastJump, casual.
  `TRACE=1,2` печатает поминутный след выбранных миров.
- `abtest.dart` — сила способностей, пар и четвёрок через штатный прогноз боя.
- `variant.py` — тот же прогон на изменённой копии ядра во временной папке (варианты правок баланса):
  `python3 tool/balance/variant.py F1 15 3`.
