Тестовая сборка Flutter-версии «Искры» 0.4.1.

**Файлы**
- `iskra-*.apk` — Android. Подписан отладочным ключом: устанавливается вручную, с разрешением установки из неизвестных источников.
- `iskra-web-*.zip` — веб-версия с сервером учётных записей (`api/`, `data/`) и `.htaccess`. Распакуйте всё в корень сайта (PHP 8 с `pdo_sqlite`).
- `iskra-windows-*.zip` — Windows 10/11 (64 бит). Распакуйте папку целиком и запустите `iskra.exe`. Windows может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
- `iskra-ios-*-unsigned.ipa` — iOS без подписи. Поставить на iPhone можно через Sideloadly или AltStore со своим Apple ID (с бесплатным Apple ID приложение работает 7 дней, потом его нужно переустановить). Для TestFlight и App Store нужен платный Apple Developer Program.

**Что нового в 0.4.1**
- Масштаб интерфейса в «Настройки → Приложение»: ×1 или авто. Авто подбирает размер кнопок, значков и текста по размеру экрана (телефон остаётся ×1).
- Верхняя строка показателей собрана к центру, на широком экране по бокам свободное поле.

**Что нового в 0.4.0**
- Окно «Настройки» вместо «Аккаунта» с вкладками: «Аккаунт» (вход и сброс прогресса), «Приложение» (графика и звук), «Статистика», «Об игре» (версия и история выпусков), «Развитие проекта».
- Музыка: три фоновые мелодии по кругу и боевая тема. Звуки боя, захвата и развития клеток, технологий, эр, прыжка и интерфейса.
- Регуляторы громкости: общая, музыка, звуки; боевую тему можно отключить. В браузере звук включается после первого касания.
- Подробная статистика: этот мир, сражения, сущности по рангам, развитие и рекорды.

**Что нового в 0.3.0**
- Настройка «Качество графики» в окне «Аккаунт»: высокое, среднее и лёгкий режим.
  Среднее — 30 кадров, без размытий и сияния в бою; лёгкий — 20 кадров, простые свечения, неподвижные портреты, меньше частиц.
  В браузере качество ограничивает и чёткость изображения (меняется после перезагрузки страницы).
  В мобильном браузере по умолчанию включено среднее качество.
- Сборки для Windows и iOS.

**Исправлено в 0.2.1**
- Белый экран на хостинге: в архиве `.htaccess` с типом `application/wasm` и разрешением WebAssembly; при сбое запуска виден экран с причиной.
