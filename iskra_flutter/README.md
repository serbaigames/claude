# Искра — Flutter-версия

Перенос браузерной игры «Искра» (веб-версия `iskra-web 7`, service worker `iskra-v27`) на Flutter:
Android, iOS и веб из одного кода. Логика и баланс перенесены из `index.html` без изменения чисел,
сохранение — в том же JSON, что пишет браузер. Учётные записи и рейтинги общие для всех платформ:
отдельный сервер на PocketBase (`server/pocketbase`, адрес `https://api.iskraplay.ru/`).

## Как запустить

```bash
flutter pub get
flutter run                      # Android / iOS / Chrome — что подключено
flutter test                     # ядро, формат сохранения, интерфейс, клиент сервера
dart run tool/sim.dart 2 90      # бот играет 90 минут с сидом 2 (проверка ядра без интерфейса)
```

Все сборки ходят на сервер `https://api.iskraplay.ru/`. Другой адрес (например, свой PocketBase на компьютере)
или пустой — без учётных записей — задаётся при сборке:

```bash
flutter run --dart-define=ISKRA_SERVER=http://127.0.0.1:8090/
```

Как поставить сервер на VPS и перенести аккаунты со старого PHP-сервера — в `server/pocketbase/README.md`.
Без сервера игра работает, прогресс хранится только на устройстве. Веб-сборка — это только `build/web/`
(и `.htaccess`), её можно выложить на любой хостинг.

Веб-движку Flutter (CanvasKit) нужны от сервера две вещи, иначе вместо игры белый экран:
файлы `.wasm` с типом `application/wasm` и `'wasm-unsafe-eval'` в `script-src`, если сайт отдаёт заголовок
Content-Security-Policy. Для Apache всё это есть в `server/site.htaccess` (положить в корень сайта как `.htaccess`),
для nginx — в `server/nginx.conf.example` и `server/iskra-security.conf`. Готовый архив из релиза уже содержит `.htaccess`.

## Устройство

```
lib/core/            — вся игра на чистом Dart, без Flutter (можно гонять в тестах и в консоли)
  defs.dart            справочники: ранги, 18 способностей, 24 эры, 6 особенностей, 11 артефактов, технологии, баланс
  model.dart           состояние игры = объект S веб-версии; toJson/fromJson в том же формате, с исправлениями старых сохранений
  game.dart            мир, экономика, персонаж, рост тьмы, угрозы клеткам
  battle.dart          бой: автоатака, способности, особенности сущностей, награды и штрафы
  meta.dart            ОП и ОС, прокачка, артефакты, прыжок искры
  forecast.dart        прогноз боя (120 прогонов) и оценка состояния мира
  sim.dart             бот для проверки ядра
lib/net/
  api.dart             клиент сервера: вход, регистрация, сохранения, рейтинги, смена пароля, удаление
  cloud_sync.dart      синхронизация как в веб-версии: раз в 30 с и при сворачивании, выбор версии при конфликте устройств
lib/ui/              — интерфейс: карта (CustomPainter), вкладки меню, окна боя, защиты, прыжка, конфликта
server/pocketbase/   — сервер учётных записей и рейтингов: правила, схема базы, установка на VPS, перенос аккаунтов
server/api/          — прежний PHP-сервер веб-версии (нужен только как источник для переноса аккаунтов)
server/*.htaccess, nginx — настройки хостинга для веб-сборки
assets/fonts/        — PT Sans и Philosopher (SIL OFL 1.1)
assets/audio/        — музыка (mp3) и звуки (wav), синтезированы скриптом tool/gen_audio.py (numpy + ffmpeg)
```

## Совместимость с веб-версией

- Ключ локального сохранения тот же — `iskra-save-v1`. Веб-сборка на том же сайте подхватит прогресс браузерной версии.
- Сервер принимает сохранения в формате веб-версии и считает по ним рейтинги (`earned`, `bestCells`, `kills`) так же,
  как PHP-сервер, — это проверяет `test/server_test.dart` на настоящем PocketBase (без него тест пропускается).
- Неизвестные поля сохранения не теряются: если веб-версия добавит новые, приложение их не сотрёт.
- Накопительная статистика приложения (бои, захваты, урон, время в игре) лежит в отдельном поле `st`; веб-версия его не читает.
- Токен входа хранится в настройках приложения (в браузере — в localStorage). Сервер разрешает запросы с любого сайта
  (CORS), а `.htaccess` веб-сборки разрешает ей ходить на `api.iskraplay.ru`.

## Что дальше

- Рисунки клеток, сущностей и иконки способностей: в веб-версии это SVG-фрагменты (`ICONS`) и рисование на canvas
  (`drawObj`, `nebula`, `starfield`) — переносятся в `Path`/`CustomPainter`. Сейчас на карте упрощённые шары.
- Значки способностей и артефактов пока символами Юникода; в веб-сборке без сети часть из них может не отрисоваться.
- Диаграмма параметров персонажа, туманности на краю видимого мира, анимации боя как в веб-версии.
